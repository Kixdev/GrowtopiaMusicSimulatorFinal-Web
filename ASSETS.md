# Assets (Not Included)

This repository intentionally ships **code only** and does **not** distribute Growtopia/Ubisoft game assets (images/sounds).

## Why assets are not included
Some assets commonly used by Growtopia-related tools may not be freely redistributable.
Keeping this repository code-only helps maintain a clean open-source distribution.

## How to run the app with assets
You must provide the required image/sound assets locally in the expected folder structure used by `notePack.js`.

### Option A (Recommended)
- Create an `assets/` folder in the project root
- Place your locally-owned/permitted assets there
- Ensure paths match what the app expects (see `notePack.js`)

### Option B
- Update `notePack.js` paths to match your own asset layout

## Important
You are responsible for ensuring you have the legal right to use any assets you place locally.
